# Security

This app is meant for private conversations, so security reports matter.

**Please report vulnerabilities privately** — use this repository's
*Security → Report a vulnerability* (GitHub private vulnerability reporting),
not a public issue.

Before reporting, read [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md): it lists
what the app deliberately does *not* protect against (for example, the AI
providers see the text you send them). Those are known limits, not
vulnerabilities — though corrections to that document are welcome.

This is a personal project maintained on a best-effort basis. It has had one
informal review and **no independent security audit**.
