# Privacy Chat

แชทกับ AI เรื่องส่วนตัวหรือเรื่องหนักๆ โดยลดจำนวน "คนกลาง" ที่เห็นบทสนทนาให้น้อยที่สุด
*(A privacy-minded AI chat app. Thai UI. Conversations are stored encrypted on your own device; a tiny stateless relay forwards messages to the AI.)*

> **ไม่ใช่บริการทางการแพทย์หรือฉุกเฉิน** ถ้าคุณหรือใครใกล้ตัวอยู่ในอันตรายเฉียบพลัน โทร **1669** (การแพทย์ฉุกเฉิน) หรือ **1323** (สายด่วนสุขภาพจิต กรมสุขภาพจิต ตลอด 24 ชม.)

## มันทำอะไร / ไม่ทำอะไร (อ่านก่อนใช้)

**ทำ**
- เก็บประวัติแชทบนเครื่องคุณเท่านั้น เข้ารหัส AES-256-GCM ด้วยกุญแจจากรหัสผ่านของคุณ (Argon2id) ไม่มีเซิร์ฟเวอร์ที่เก็บบทสนทนา
- ปกปิดอีเมล เบอร์โทร เลขบัตรประชาชน/บัตรเครดิต และลิงก์ก่อนส่งให้ AI แล้วสลับกลับในหน้าจอคุณ
- ลบข้อมูลทั้งหมดทันทีด้วยการกด **Esc 3 ครั้ง** (มือถือ: แตะชื่อแอป 3 ครั้ง) และล็อกอัตโนมัติเมื่อไม่ได้ใช้งาน 5 นาที

**ไม่ทำ**
- **AI ผู้ให้บริการเห็นข้อความที่คุณส่ง** เพื่อตอบ (Anthropic Claude เป็นหลัก, OpenAI เป็นตัวเลือกที่สอง) ผ่าน API เชิงพาณิชย์ที่โดย default ไม่นำไปเทรน แต่ OpenAI เก็บ log ตรวจการใช้งานผิดปกติได้ถึง 30 วัน
- ไม่ปกปิดชื่อคนและสถานที่ในข้อความ
- ยังไม่ผ่านการตรวจสอบความปลอดภัยโดยผู้เชี่ยวชาญอิสระ

รายละเอียดครบ (ใครเห็นอะไร, อะไรไม่ปกป้อง, ข้อจำกัดของ panic wipe): **[docs/THREAT_MODEL.md](docs/THREAT_MODEL.md)**

## โครงสร้าง

```
web/    React + TypeScript + Vite   — UI, การเข้ารหัส, การปกปิดข้อมูล (ทำงานในเบราว์เซอร์)
relay/  Cloudflare Worker           — ตัวกลางไร้สถานะ ซ่อน API key ไม่เก็บ/ไม่ log เนื้อหา
docs/   THREAT_MODEL.md
```

เหตุที่ต้องมี relay: ไม่ให้ API key อยู่ในเบราว์เซอร์ มันส่งต่อข้อความให้ Claude (และ OpenAI ถ้าตั้ง key) แล้ว stream คำตอบกลับ

## รันในเครื่อง

ต้องมี Node.js 22+ และ API key ของ Anthropic

```bash
# 1) relay
cd relay
cp .env.example .env          # ใส่ ANTHROPIC_API_KEY (อย่างอื่นเป็นตัวเลือก)
npm install
npm run dev                   # http://127.0.0.1:8787

# 2) web (เทอร์มินัลอีกอัน)
cd web
cp .env.example .env
npm install
npm run dev                   # http://localhost:5173
```

เปิดเว็บ ยอมรับประกาศความปลอดภัย แล้วตั้งรหัสผ่าน **ลืมรหัสผ่านแล้วกู้ข้อมูลไม่ได้** (ไม่มีใครกู้ให้ได้ รวมถึงผู้สร้าง)

ทดสอบ: `npm test` ใน `web/` (ตรรกะปกปิดข้อมูล, panic, auto-lock, การอ่าน key จากลิงก์) และ `npm run typecheck` ใน `relay/`

ตัวเลือก: `?dev=1` ต่อท้าย URL เพื่อแสดงชื่อโมเดลและจำนวนโทเค็นในบับเบิล (`?dev=0` ปิด)

## Deploy

- **relay:** `cd relay && npx wrangler secret put ANTHROPIC_API_KEY` (และ `RELAY_ACCESS_KEY` — **จำเป็นเมื่อ deploy** ไม่งั้นใครเจอ URL ก็ใช้โควตา API ของคุณได้; ทางเลือก: `OPENAI_API_KEY`, `GOOGLE_API_KEY`) แล้ว `npx wrangler deploy` เพิ่มโดเมนเว็บของคุณใน `RELAY_ALLOWED_ORIGIN` ที่ `relay/wrangler.toml` ก่อน
- **web:** `cd web && VITE_RELAY_URL=<URL ของ relay> npm run build` แล้วนำ `dist/` ไปวางที่ static host ใดก็ได้
- เปิดเว็บครั้งแรกบนแต่ละอุปกรณ์ด้วย `<web-url>/#key=<RELAY_ACCESS_KEY>` (ส่วนหลัง `#` ไม่ถูกส่งไปเซิร์ฟเวอร์และแอปลบมันออกจากแถบที่อยู่ทันที)

แผนฟรีของ Cloudflare Workers จำกัด CPU 10 ms ต่อคำขอ คำตอบยาวมากอาจถูกตัดกลางทาง ดูรายละเอียดใน `CLAUDE.md`

## ปรับแต่งบุคลิกของ AI

ข้อความ prompt ทั้งหมดอยู่ที่ `relay/src/prompts.ts` **ก่อน deploy เวอร์ชันของคุณเอง ให้แก้ส่วน "คำตอบเฉพาะที่เจ้าของแอปกำหนดไว้"** (มีชื่อผู้สร้างต้นฉบับและมุกเฉพาะตัวอยู่) ให้เป็นของคุณ
