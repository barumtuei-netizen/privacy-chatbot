# Threat model

เอกสารนี้บอกตรงๆ ว่าแอปปกป้องอะไร ไม่ปกป้องอะไร และใครเห็นข้อมูลอะไรบ้าง
ถ้าโค้ดเปลี่ยนจนข้อใดไม่จริงอีกต่อไป ให้แก้เอกสารนี้ในการเปลี่ยนแปลงเดียวกัน

## ใครเห็นอะไร

| ผู้เกี่ยวข้อง | เห็นอะไร | หมายเหตุ |
|---|---|---|
| **Anthropic (Claude)** | ข้อความ 40 ข้อความล่าสุด (ผ่านการปกปิดแล้ว) + บริบทส่วนตัว ("เกี่ยวกับฉัน") | API เชิงพาณิชย์ ไม่นำไปเทรนโดย default (ตรวจ 2026-09-07, ดู CLAUDE.md) ยังไม่ใช่ ZDR |
| **OpenAI (สมองที่สอง, ถ้าตั้ง key)** | เฉพาะข้อความ 40 ข้อความล่าสุด (ผ่านการปกปิดแล้ว) ไม่เห็นบริบทส่วนตัว | ตรวจนโยบายแล้ว 2026-09-21 ([your-data](https://developers.openai.com/api/docs/guides/your-data)): API **ไม่นำไปเทรนโดย default** แต่ **เก็บ abuse-monitoring log ได้ถึง 30 วัน** (มีเนื้อหา prompt/response) และอาจเก็บ/ให้คนตรวจนานกว่านั้นถ้า "จำเป็นเพื่อสืบสวนหรือป้องกันกิจกรรมเสี่ยงร้ายแรง" (ไม่ระบุว่าเนื้อหาเรื่องทำร้ายตัวเองเข้าข่ายหรือไม่). relay ใช้ Chat Completions ซึ่งไม่มี application-state retention. ZDR/Modified Abuse Monitoring ต้องขออนุมัติกับฝ่ายขาย |
| **Google (TTS)** | ข้อความคำตอบที่ผู้ใช้กดปุ่มอ่านออกเสียง | ตัดสินใจโดยเจ้าของโปรเจกต์ (2026-09-21): ไม่ถามยืนยัน แต่ป้ายบนปุ่มบอกชัดว่า "ข้อความนี้จะถูกส่งให้ Google สร้างเสียง" ผู้ใช้เลือกกดเอง อีเมล ลิงก์ เบอร์โทร เลขบัตร ถูกตัดเป็นคำกลางๆ ก่อนส่ง (`redactForSpeech`) ชื่อคนและสถานที่ส่งตามที่เขียน |
| **Relay (Cloudflare Worker)** | ทุกอย่างที่ส่งผ่านในหน่วยความจำ (หลังปกปิดแล้ว) | ไม่ log เนื้อหา (ปิด observability/logs ใน `wrangler.toml`) ไม่เก็บลงดิสก์ Cloudflare ในฐานผู้ให้บริการรัน Worker เห็น traffic ได้ในทางทฤษฎี (ระดับความไว้ใจเท่ากับที่เห็นเว็บ Pages อยู่แล้ว) |
| **Ollama (embedding)** | ข้อความจริงทั้งหมด | รันบนเครื่องคุณเอง ไม่ออกเครือข่าย (ถ้าไม่ได้รัน ระบบข้ามไปเอง) |

## สิ่งที่ปกป้อง

- **ข้อมูลที่เก็บบนเครื่อง**: เนื้อหาแชท บริบทส่วนตัว (และความทรงจำเก่าที่ยังค้างในฐานข้อมูลแต่ไม่ถูกใช้แล้ว) เข้ารหัส AES-256-GCM ด้วยกุญแจจาก passphrase (Argon2id) กุญแจอยู่ในหน่วยความจำเท่านั้น ถ้าเครื่องถูกยึดขณะล็อกอยู่ ผู้ยึดอ่านเนื้อหาไม่ได้หากไม่มี passphrase
- **การปกปิดก่อนส่ง** (`web/src/privacy/scrub.ts`): อีเมล เบอร์โทร เลขบัตรประชาชน เลขบัตรเครดิต/บัญชี และลิงก์ ถูกแทนด้วยรหัสก่อนออกจากเครื่อง และสลับกลับเฉพาะในหน้าจอผู้ใช้ ทำงานเงียบ ไม่มีหน้าตั้งค่า

## สิ่งที่ *ไม่* ปกป้อง

- **ชื่อคน สถานที่ และเรื่องราว** — ไม่ถูกปกปิดเลย (ไม่มีการเดาชื่อ ภาษาไทยไม่มีเว้นวรรค และตอนนี้ไม่มี UI ให้ผู้ใช้ระบุคำเอง) เนื้อเรื่องเองก็ระบุตัวตนได้
- **เนื้อหาที่ส่งให้ AI** — AI ผู้ให้บริการเห็นเรื่องราว (ในรูปที่ปกปิดแล้ว) เพื่อตอบ การเข้ารหัสในเครื่องไม่ได้ปกป้องช่วงนี้
- **Metadata ที่ไม่ได้เข้ารหัสใน IndexedDB**: `role`, `ts` (เวลา), `source` ของทุกข้อความ และขนาดของ ciphertext (บอกความยาวข้อความคร่าวๆ) — คนที่เข้าถึงโปรไฟล์เบราว์เซอร์ได้เห็นว่าคุยเมื่อไหร่ บ่อยแค่ไหน
- **localStorage แบบข้อความเปล่า**: relay access key (ถ้าตั้ง), การรับทราบประกาศความปลอดภัย
- **ลิงก์ `#key=...`**: ส่วน `#` ไม่ถูกส่งไปเซิร์ฟเวอร์และแอปลบมันออกจากแถบที่อยู่ทันที แต่ประวัติเบราว์เซอร์/บุ๊กมาร์กที่สร้างจากลิงก์เดิมยังมี key เต็ม ผู้ที่ได้ key ใช้โควตา API ของคุณได้ (อ่านแชทของใครไม่ได้ เพราะแชทเก็บในเครื่องผู้ใช้) — ถ้าหลุด ให้เปลี่ยน `RELAY_ACCESS_KEY` บน Fly.io
- **เครื่องที่ติดมัลแวร์ / keylogger / ส่วนขยายเบราว์เซอร์อันตราย / XSS** — เห็นข้อความตอนพิมพ์และตอนกุญแจอยู่ในหน่วยความจำ
- **คนที่เห็นหน้าจอ** — มี panic wipe (กด Esc 3 ครั้ง / แตะชื่อแอป 3 ครั้ง ลบทุกอย่างทันทีไม่ถามซ้ำ) และ auto-lock (ไม่มีการใช้งาน 5 นาที → ทิ้งกุญแจ ข้อความ และดัชนี embedding ออกจากหน่วยความจำ กลับหน้า passphrase; ไม่ล็อกระหว่างที่ AI กำลังตอบ; ร่างที่พิมพ์ค้างจะหาย) ค่าอยู่ที่ `IDLE_LOCK_MS` ใน `web/src/privacy/idle.ts`
- **Traffic analysis** — ผู้ดูเครือข่ายเห็นว่ามีการเชื่อมต่อกับ relay และขนาด/จังหวะของ request

## ข้อจำกัดของ panic wipe (`web/src/privacy/panic.ts`)

- ลบด้วยการล้างทุก store แล้วลบฐานข้อมูล IndexedDB + ล้าง localStorage/sessionStorage แล้วย้ายหน้าไปหน้าว่าง (`replace` ปุ่ม Back จึงไม่พากลับ) **นี่ไม่ใช่การเขียนทับข้อมูลบนดิสก์** — การกู้คืนด้วยเครื่องมือนิติวิทยาศาสตร์ระดับดิสก์ยังเป็นไปได้ในทางทฤษฎี แต่ข้อมูลที่เหลือเป็น ciphertext ที่ต้องใช้ passphrase
- **ประวัติของเบราว์เซอร์ (URL ที่เคยเข้า) ไม่ถูกลบ** แอปเว็บลบเองไม่ได้ ผู้ใช้ต้องล้างประวัติเอง หรือใช้หน้าต่างส่วนตัว
- ไม่ลบสิ่งที่ออกไปแล้ว: ข้อความที่ส่งให้ Anthropic/OpenAI/Google ตามนโยบายของแต่ละเจ้า
- ถ้าเปิดแอปไว้หลายแท็บ แท็บอื่นจะยังเห็นข้อมูลในหน่วยความจำจนกว่าจะปิด
- ลบโดยไม่ถามยืนยันโดยตั้งใจ — กด Esc 3 ครั้งติดกันโดยไม่ตั้งใจ = ข้อมูลหายถาวร

## ช่องว่างที่รู้แล้ว (ยังไม่แก้)

1. TTS ส่งชื่อคน/สถานที่จริงให้ Google เมื่อผู้ใช้กดปุ่ม (แจ้งไว้บนปุ่ม ไม่มีหน้าต่างยืนยัน — ตั้งใจ) ปิดได้โดยไม่ตั้ง `GOOGLE_API_KEY` ที่ relay
2. OpenAI เก็บ log ได้ถึง 30 วันและมีข้อยกเว้นให้คนตรวจ — ข้อความบนหน้าจอบอกแค่ "ไม่เทรน" (จริง) ยังไม่ได้บอกเรื่อง 30 วัน
3. ไม่มี duress passphrase; auto-lock ล้างข้อมูลที่ React/embedding ถือไว้ แต่ JavaScript ไม่รับประกันว่าจะเขียนทับหน่วยความจำจริงทันที (รอ garbage collection)
